React state is a render snapshot

공식 React 문서는 event handler, render별 state snapshot, handler 이후 처리되는 update queue를 구분한다.

onEnter(event) {
  setPending(true)   // queue an update
  startTurn(input)   // a separate lifecycle
}

이 코드는 설명용 의사코드이며 프로젝트 관찰 source가 아니다.

07 · Durability and Recovery실패 뒤에 남은 상태를 먼저 센다
Failure-aware conclusion

재시도 전에 “이미 일어난 것”을
확정해야 한다

UI를 다시 그리는 것, generator를 다시 시작하는 것, tool effect를 다시 실행하는 것은 서로 다른 복구 동작이다.

정상 경로

  1. Enter event를 message/context로 정규화한다.
  2. generator turn이 progressive event를 yield한다.
  3. tool request는 permission과 client effect를 거친다.
  4. tool_result가 continuation으로 돌아온다.
  5. terminal reason과 durable checkpoint를 기록한다.

실패·중단 경로

  1. 마지막 durable checkpoint와 effect receipt를 읽는다.
  2. UI projection만 사라졌는지 turn도 중단됐는지 구분한다.
  3. idempotent하지 않은 effect는 자동 반복하지 않는다.
  4. cancel/error를 generator에 전달하고 cleanup을 확인한다.
  5. resume, compensate, abort 중 하나를 증거와 함께 선택한다.
