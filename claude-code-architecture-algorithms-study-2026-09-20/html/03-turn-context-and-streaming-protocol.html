    bash/slash variant는 model 호출 전 local effect를 만들 수 있어 permission과 표시 문자열을 분리해야 한다.

    현재 설계가 선택한 trade-off와 비용

    입력 의미를 REPL widget이 아니라 별도 processor에 둬 headless와 재사용한다. 이 선택의 계산·운영 비용은 command lookup과 content 크기에 비례. 일반적으로 O(C + N).로 기술되지만, 비용 표기만으로 중복 effect나 부분 상태의 의미가 해결되지는 않는다.

    실패·중단 뒤에 실제로 남을 수 있는 상태

    prefix 중첩, hook output truncation, display/submit payload drift는 사용자가 승인한 것과 실행된 것을 다르게 만든다. 이때 함께 대입할 반례는 prefix ambiguity, hook output truncation, 그리고 display text와 submit payload drift이다. 이들을 모두 하나의 “실패”로 접으면 retry와 cleanup이 무엇을 이어받아야 하는지 알 수 없다.

    관측이 다음 판단에 답하게 하는 법

    origin, parsed variant, displayed value, submitted payload digest를 연결하면 입력 변형을 추적할 수 있다. 로그의 존재보다 중요한 것은 이 관측값이 같은 요청·state·effect를 가리키며, 복구 또는 중단 결정을 실제로 바꿀 수 있는가이다.

    yield는 여러 번 반환하는 문법이 아니다

    yield는 실행 프레임을 보존한 채 IteratorResult를 내보내는 suspension point다. return은 같은 프레임을 terminal 상태로 만들고, throw는 정상 완료가 아닌 abrupt completion을 소비자에게 전파한다.

    먼저 바로잡을 오개념

    “함수를 여러 번 나눠 실행한다”는 말은 입문용 직관으로는 유용하지만, 무엇이 보존되고 누가 재개하며 종료 값이 어디로 가는지를 설명하지 못한다. 이 프로젝트를 읽으려면 producer frame, iterator protocol, consumer loop를 서로 다른 층으로 분리해야 한다.

    다음 표는 같은 generator에서 일어나지만 의미가 다른 세 가지 completion을 생산자 프레임, iterator protocol, query, UI의 층으로 나누어 비교한다.

    관찰 축yield valuereturn terminalthrow error
    생산자 실행 프레임local variable·instruction pointer를 보존하고 suspended가 된다.completed가 되어 정상 경로로는 다시 실행되지 않는다.abrupt completion으로 빠져나가며 내부 catch가 없으면 닫힌다.

    줄을 따라 확인할 관찰점

    먼저 볼 표현새 chunk마다 warning/timeout timer를 reset한다.

    그 표현이 만든 조건첫 chunk 전 대기는 TTFB이고 이후 gap은 stall로 분리한다.

    그 표현이 만든 조건timeout은 streamIdleAborted와 firing timestamp를 남긴 뒤 resource release를 호출한다.

    그 표현이 만든 조건loop 종료 뒤 watchdog abort인지 확인해 정상 completion과 다른 recovery를 택한다.

    언어와 런타임은 여기까지 보장한다

    timer callback은 stream iterator와 별도 event-loop task다. boolean과 timestamp는 두 실행 경로가 합류할 때 terminal 원인을 전달하는 handoff state이며, timer cleanup은 이미 끝난 stream에 뒤늦은 abort가 들어오지 않게 한다.

    프로젝트가 이 메커니즘에 맡긴 책임

    이 코드는 latency telemetry, liveness, abort propagation, fallback transport를 하나의 terminal classification으로 연결한다. 단순 timeout wrapper보다 “왜 loop가 끝났는가”를 보존하는 것이 핵심이다.

    경계를 잘못 읽을 때 생기는 위험

    timer를 reset하거나 clear하지 않으면 정상 stream을 abort할 수 있고, watchdog abort를 정상 EOF로 취급하면 partial message를 성공으로 정산한다. warning/stall telemetry가 effect control과 같은 flag를 바꾸면 관찰 코드가 동작을 왜곡한다.
