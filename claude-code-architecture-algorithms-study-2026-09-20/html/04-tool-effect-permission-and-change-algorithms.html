구현에서 직접 확인되는 범위

공통 pipeline은 unknown tool, abort, hook, permission, sandbox routing, call, result를 protocol-valid message로 만든다. 병렬성은 입력별로 계산하고 여러 hook decision은 보수적 precedence로 합성한다.

운영을 말할 때 남겨야 할 경계

파일과 shell 효과는 OS 상태와 경쟁하며 외부 hook process·HTTP endpoint까지 trust boundary에 들어오므로 타입 안전성만으로 보호되지 않는다.

이 보고서가 추측으로 채우지 않는 것
