    ALGORITHM A25 · 설명의 보장 경계

    이 구현이 지키려는 조건과, 설명이 멈춰야 하는 조건

    여기서 불변조건은 형식적 증명의 결론이 아니다. 어느 전이가 의도한 의미를 보존했는지 읽고, 어떤 반례를 넣어 설명의 범위를 확인할지를 정하는 학습 도구다.

    전이 전후에 확인할 조건

    • 상태·계산 모델의 질문으로 읽기. 같은 UUID를 두 번 방문하지 않는다.
    • 내구성·복구의 질문으로 읽기. 결과 순서는 root→leaf다.
    • 상태·계산 모델의 질문으로 읽기. broken parent를 조용히 다른 branch로 대체하지 않는다.

    ALGORITHM A25 · effect와 운영

    정상 경로 뒤에 남는 effect와 실패 뒤에 남는 상태를 구분한다

    selected leaf에서 parentUuid를 따라가 seen set에 넣고 root 도달 뒤 뒤집는다.

    effect가 시작되고 관찰되는 경계

    복원된 chain이 다음 model context가 되므로 제외된 branch는 resume에서 보이지 않는다.

    현재 설계가 선택한 trade-off와 비용

    append record를 직접 정렬하기보다 explicit parent relation을 canonical lineage로 사용한다. 이 선택의 계산·운영 비용은 주 chain 길이 L에 O(L), 후속 recovery 별도.로 기술되지만, 비용 표기만으로 중복 effect나 부분 상태의 의미가 해결되지는 않는다.
