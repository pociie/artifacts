먼저, 지금 보고 있는 시스템의 상태를 고정한다

MCP, plugin, skill은 서로 다른 확장 surface다. remote/bridge는 local message와 authority를 wire protocol로 다시 투영한다. build-time feature와 runtime configuration/GrowthBook이 제품 variant를 만든다.

구현에서 직접 확인되는 범위

외부 identity는 normalization/schema를 거쳐 Tool 언어로 투영되고, remote SDK adapter와 bounded reconnect가 local runtime과 transport failure를 연결한다. settings/migration/analytics가 장기 운영을 보조한다.

운영을 말할 때 남겨야 할 경계

코드에는 reconnect, polling, batching, checksum, migration이 보이지만 실제 server replay·조직 운영·활성 값은 unknown이다.

이 보고서가 추측으로 채우지 않는 것

plugin 공급망 정책 전체, remote server의 replay/retention contract, remote managed settings 실제 배포 범위, telemetry retention/backend, 그리고 공식 refactor roadmap은 현재 snapshot만으로 확정할 수 없다. 이후의 설명은 이 공백을 유지한 채, 실제 코드가 보여 주는 구조와 보장만을 다룬다.
