THESIS01

context는 문자열이 아니라 컴파일 결과다

최종 API 입력은 사용자 prompt 하나가 아니다. system policy, 환경, 도구 schema, 대화 이력, attachment, memory, compact projection을 규칙에 따라 조립한 값이다.

따라서 prompt engineering만 보면 핵심을 놓친다. 무엇을 포함하고 제외하는지, 어떤 순서가 cache key를 만드는지, 어떤 메시지가 UI에는 보이지만 API에는 제거되는지가 더 결정적이다.

DYNAMIC TOOL SET06

활성 tool pool은 permission과 런타임 상태의 함수다

NORMALIZATION08

한 상태에서 여러 표현을 만든다

내부 Message를 API parameter, SDKMessage, terminal UI row, JSONL transcript로 그대로 복사하지 않는다. 소비자 계약에 맞는 projection이 필요하다.

READ STATE09

읽기는 정보 획득이자 쓰기 권한의 전제다

FileReadTool은 결과를 보여 주는 데서 끝나지 않고 file path, content, timestamp, partial-view 여부를 readFileState에 남긴다. Edit는 이 state를 optimistic lock처럼 사용한다.

Read-before-write는 prompt 지시가 아니다Edit.validateInput과 call이 runtime에서 강제한다. 모델이 “읽었다”고 말하는 것과 readFileState에 full read가 존재하는 것은 다르다.

이 연결 때문에 context와 effect가 분리되어도 완전히 독립적이지 않다. 관찰의 freshness가 후속 효과의 admissibility를 결정한다. partial read는 내용 일부만 알기 때문에 전체 파일 edit의 전제로 인정되지 않는다.

REFACTORING17

context compiler를 명시적 단계로 만들기

현재 로직을 단순히 한 파일로 모으면 dependency cycle과 feature 결합이 커진다. 대신 immutable intermediate representation과 cache contract를 먼저 정의한다.

  • 각 단계는 pure projection을 기본으로 하고 effect는 loader/adapter에 둔다.
  • cacheSegments를 값으로 표현해 순서와 dynamic suffix를 검증한다.
  • provenance를 유지해 UI visibility, model visibility, authority를 혼동하지 않는다.
  • compact/snip을 rewrite policy로 만들고 replay equivalence test를 둔다.
우선 보존할 oracle
동일 fixture에 대해 provider request JSON, cache segment hash, tool_use/result pairing, resume 후 message projection이 같아야 한다.

CASE STUDY18

한 Edit turn에서 context가 하는 일

파일 수정 기능을 실제로 성립시키는 문맥은 prompt보다 넓다.

  1. system prompt가 Read-before-Edit 사용법과 도구 vocabulary를 제공한다.
  2. 사용자 prompt와 repository memory가 대상 변경의 의미를 제공한다.
  3. Read 결과가 내용과 timestamp를 message/readFileState 양쪽에 남긴다.
  4. Edit schema가 old_string/new_string/file_path라는 행동 언어를 제한한다.
  5. Edit result가 patch와 성공 정보를 다음 reasoning에 되돌린다.
  6. 테스트 Bash result가 변경이 목표를 만족하는지 새 context가 된다.
  7. transcript와 compact policy가 다음 turn/resume에서 필요한 부분을 보존한다.
학습 포인트“prompt가 좋아서 편집했다”가 아니라, 관찰·행동 schema·runtime guard·결과 환류가 함께 모델의 작업 능력을 만든다.
