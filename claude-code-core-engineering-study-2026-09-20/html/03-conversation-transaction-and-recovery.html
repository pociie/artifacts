THESIS01

turn은 transaction처럼 다뤄지지만 ACID transaction은 아니다

모델 응답, tool effect, UI projection, transcript write가 단계적으로 발생한다. 중간 실패 시 모두 rollback할 수 없으므로 “무엇이 발생했는가”를 일관되게 남기는 것이 핵심이다.

Turn = state transition + external effects + reconciliation record

이 시스템의 성공은 마지막 assistant text만으로 정의되지 않는다. tool 결과가 다음 request에 합류하고, terminal reason이 caller에 전달되며, process가 죽어도 resume가 이미 수락된 사용자 입력과 발생한 effect를 복원해야 한다.

GENERATOR03

async generator는 상태 머신의 외부 관찰 계약이다

generator가 내부 State를 대신하지 않는다. 내부 transition을 수행하면서 event를 즉시 내보내고, 종료 시에는 Terminal 값을 반환하는 인터페이스다.

yield는 UI/SDK에 관찰을 제공하면서 continuation과 local frame을 보존한다. return은 terminal reason을 iterator completion value로 구분한다. 소비자가 .return()하거나 throw가 발생하면 wrapper의 완료 코드가 실행되지 않는 비대칭도 설계에 포함된다.

STOP HOOK10

“모델이 끝났다”와 “turn이 끝났다”는 다르다

tool_use가 없더라도 stop hook이 continuation을 막거나 새 blocking message로 재시도를 요구할 수 있다.

stop hook blocking 뒤 reactive compact guard를 잘못 초기화하면 compact→여전히 too long→hook block→compact가 반복될 수 있다. 코드 주석은 실제로 수천 API call을 태울 수 있는 무한 루프를 설명한다.

개발 노력의 핵심policy extension을 loop에 넣을 때는 “다시 실행할 수 있다”가 아니라, 재시도 fingerprint와 monotonic guard가 있는지를 확인해야 한다.

TRANSCRIPT12

transcript는 로그 파일이 아니라 재실행 상태다

사용자 입력을 model call 전에 기록하는 이유는 응답 전 process kill에도 session을 resume하기 위해서다.

REFACTORING20

turn engine을 event protocol과 policy로 분리한다

REPL/SDK 통합의 목표는 component를 작게 만드는 것이 아니라 동일 turn semantics를 한 owner가 갖게 하는 것이다.

  • CoreEvent는 React node나 SDK wire type을 포함하지 않는다.
  • Terminal과 recovery transition을 discriminated union으로 닫는다.
  • journal write 위치를 engine lifecycle에 명시하고 durability mode를 입력으로 둔다.
  • REPL migration 전 golden trace를 만들어 event/order/terminal을 비교한다.
가장 큰 위험
interactive path의 latency·cancel·prompt restore와 SDK path의 replay/flush가 서로 다른 암묵 계약을 갖고 있다. 공통분모만 추출하면 양쪽 의미를 잃을 수 있다.

CONCLUSION21

복구 가능한 turn의 조건

모든 성공과 실패가 하나의 truth로 합류할 때만 다음 turn과 resume가 올바르다.

  • yield된 partial event와 committed conversation state를 구분한다.
  • 모든 tool_use/result id pairing을 abort·error·fallback에서도 보존한다.
  • 회복 가능한 오류는 provisional로 보류하고 반복 guard를 둔다.
  • terminal reason을 caller가 해석할 값으로 반환한다.
  • 사용자 입력과 외부 effect를 process crash 전에 필요한 수준으로 journal에 남긴다.
  • REPL·SDK·resume가 같은 core 사건을 의미상 동등하게 투영하는지 trace로 검증한다.
