ORDER05

순서는 의미와 비용을 동시에 바꾼다

왜 같은 block 집합의 재정렬이 동등하지 않은가?

instruction precedence, recency, tool/result adjacency, cache prefix가 모두 순서에 의존한다. 따라서 context는 set이 아니라 ordered, typed sequence다. “내용이 같다”는 것은 provider request의 동등성을 보장하지 않는다.

구조적 귀결정렬 안정성은 performance 최적화가 아니라 semantic/cache compatibility contract가 된다.

ATTACHMENTS09

OBSERVER COPY13

provider fallback이나 observer instrumentation은 같은 request를 다른 목적으로 본다. 관찰을 위해 mutable message를 수정하면 cache identity와 실제 호출 의미까지 변할 수 있다. 그래서 관찰 projection은 execution input과 identity를 분리해야 한다.

CONCLUSION18

Context는 모델 앞의 작은 운영체제다

이 권에서 남겨야 할 한 문장은 무엇인가?

모델이 보게 되는 세계는 발견되는 것이 아니라, provenance·budget·cache·policy 아래 컴파일된다.

따라서 context bug는 prompt wording 문제만이 아니다. 잘못된 source 선택, ordering, projection leakage, lossy migration, cache coupling도 모두 같은 제품 결과를 바꾼다.
