DELEGATION05

yield*는 stream adapter의 합성 도구

상위 generator가 하위 generator의 모든 값을 다시 포장하지 않고 전달하면서 최종 return 값도 받을 수 있다.

실제 query()는 내부 queryLoop()의 이벤트를 그대로 노출하면서 정상 종료 뒤 command lifecycle 완료를 기록한다. throw나 iterator의 .return()에서는 이 꼬리 코드가 실행되지 않는다는 주석도 있다.

설계 포인트
delegation은 transport wrapping처럼 보이지만 terminal semantics를 바꿀 수 있다. 하위 generator의 throw/return/consumer cancellation이 상위 cleanup과 어떻게 합성되는지 반드시 본다.

EXHAUSTIVENESS09

경계

generic + schema

제어
